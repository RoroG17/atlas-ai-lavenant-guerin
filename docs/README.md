# Documentation Atlas AI

Bienvenue dans la documentation technique du projet **Atlas AI**, l'assistant intelligent interne d'ATLAS Consulting.

Cette documentation est conçue pour permettre à tout développeur ou décideur technique de comprendre, installer et opérer le système.

## Table des Matières

1.  [**Architecture**](architecture.md) : Comprendre les composants et le flux de données (RAG, Guardrails).
2.  [**Installation**](installation.md) : Guide pas-à-pas pour configurer l'environnement.
3.  [**Configuration**](configuration.md) : Détail des options disponibles dans `atlas.yaml`.
4.  [**Monitoring**](monitoring.md) : Observabilité, logs structurés et analyse des performances.
5.  [**Gouvernance**](governance.md) : Sécurité des données, RGPD et Guardrails.
6.  [**Opérations**](operations.md) : Guide d'exploitation (maintenance, purges).
7.  [**Sécurité**](security.md) : Modèle de menaces et mesures de protection.
8.  [**ADR (Architecture Decision Records)**](adr/) : Historique des décisions structurantes.
